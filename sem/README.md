# KFJP coverage-breadth structural equation model

This directory contains the SEM analysis used for the manuscript's KFJP coverage-breadth results (main-text Fig. 4B and SI Section S6), together with the two scripts that construct its scholar-level variables.

The four fitted submodels, discipline controls, residual covariance, and coefficient/path-summary calculations are retained from the study scripts. This distribution changes input/output paths for portability. It does not add another candidate SEM, re-estimate the manuscript results, or change the manuscript figures.

## Files

- `build_hcr_sem_dataset.py`: builds scholar-level publication, citation, portfolio, and academic-age variables from existing matrices, WoS exports, and a journal-tier lookup.
- `build_kfjp_indicator_test_dataset.py`: adds KFJP coverage breadth and auxiliary descriptive columns. The SEM uses only the columns listed below, not every auxiliary column this script exports.
- `run_hcr_sem_kfjp_coverage_breadth.R`: fits the reported piecewise SEM and exports diagnostics, standardized paths, net-path summaries, and plotting outputs.
- `requirements.txt`: Python dependencies for the variable-construction scripts.

## Dependencies

Use Python 3.10 or newer for the Python scripts. Install their dependencies from the repository root:

```sh
python -m pip install -r sem/requirements.txt
```

The R analysis imports `piecewiseSEM`, `tidyverse`, `ggplot2`, and `patchwork`. Install these in your own R environment if needed:

```r
install.packages(c("piecewiseSEM", "tidyverse", "ggplot2", "patchwork"))
```

The path-summary code uses dplyr's `.by` syntax. Exact package versions from the original analysis are not supplied here; record `sessionInfo()` and your Python package versions when running the analysis. No new numerical reproduction is claimed by publishing these scripts.

## Option A: run from an already constructed analysis CSV

Run from the repository root:

```sh
Rscript sem/run_hcr_sem_kfjp_coverage_breadth.R /path/to/kfjp_indicator_test_dataset.csv /path/to/output_directory
```

The input is one row per scholar and must contain these columns. Values marked `log1p` must already be transformed; the R script does not transform them again.

| Column | Definition used in the study |
| --- | --- |
| `subject` | One of `phy`, `che`, `bio`, `mat`; physics is the reference category. |
| `citation_perf` | `log1p(total citations / total publications)`. |
| `productivity` | `log1p(total publications)`. |
| `career_age` | `log1p(2026 - earliest publication year + 1)`. |
| `breadth` | `log1p(number of distinct journals with publications)`. |
| `concentration` | Sum of squared journal-level publication shares (HHI). |
| `q1h_non_kfjp_pub` | Share of all publications in Q1H journals outside the field's KFJP. |
| `kfjp_pub` | Share of all publications in the field's KFJP. |
| `kfjp_surplus` | KFJP citation share minus KFJP publication share. |
| `kfjp_coverage_breadth` | `log1p(number of distinct KFJP journals with publications)`. |

The R script creates three discipline indicators, removes rows missing the nine numerical analysis variables, and fits four linear submodels with responses `q1h_non_kfjp_pub`, `kfjp_pub`, `kfjp_surplus`, and `citation_perf`. All four include discipline indicators. KFJP coverage breadth is an observed predictor, not a separately fitted response. Residual covariance is specified between the two publication-share responses.

## Option B: construct variables from the original input structure

Raw scholar records, publication/citation matrices, journal-tier files, and derived scholar-level CSVs are **not included** in this code upload. These scripts consume existing matrices; they do not download WoS records or construct the initial matrices from scratch. Supply your own authorized inputs using the layout below:

```text
sem/data/
  DATA/
    期刊分区.xlsx
  4学科data/
    phy/
      <scholar-id>.xlsx
      学者-期刊矩阵/
        学者-有效期刊论文篇数矩阵.xlsx
        学者-有效期刊被引次数矩阵.xlsx
      百分之几筛选结果/
        P_ij_筛选后.xlsx
        C_ij_筛选后.xlsx
    che/  (same layout)
    bio/  (same layout)
    mat/  (same layout)
```

- Matrix rows are scholar identifiers and columns are journal names; the first column is the row index. Publication and citation matrices must have matching row/column order. KFJP names must match the field-specific lists in `TRUE_KFJP_BY_SUBJECT`.
- `<scholar-id>.xlsx` files must correspond to the matrix row identifiers. The reader expects a WoS export with first-column metadata labels `h-index`, `Results found`, `Sum of the Times Cited`, and `Average Citations per Item`, followed by a row whose first cell is `Title` and a publication table containing `Publication Year`.
- `期刊分区.xlsx` must contain `NAME` and `Quartile` columns. The script recognizes `Q1H` as the high-tier label. This lookup is not downloaded or generated by these scripts. Unmatched journals remain in the full-record denominators but not the Q1H numerator.
- The academic-age reference year is intentionally fixed at **2026**, matching the study; do not replace it with the current year when reproducing that analysis.

Then run, from the repository root:

```sh
python sem/build_hcr_sem_dataset.py
python sem/build_kfjp_indicator_test_dataset.py
Rscript sem/run_hcr_sem_kfjp_coverage_breadth.R
```

By default, the Python scripts read/write within `sem/data`, and the R script reads the resulting `sem/data/DATA/KFJP_superiority_tests/kfjp_indicator_test_dataset.csv` and writes to `sem/outputs`. To use an existing input root, set the `KFJP_SEM_BASE` environment variable to that root before running the scripts. Preserve the `DATA` and `4学科data` subdirectories within it. The R script's two optional arguments override its input CSV and output directory.

## Outputs and interpretation

The analysis writes the SEM summary, Fisher's C, AIC, directed-separation tests, standardized path coefficients, and summed standardized path summaries. Output filenames/column names such as `net_effect` and `EffectSize` retain their legacy names for compatibility; they represent the manuscript's **net associations**, not causal effects or formally estimated synergistic interactions.

The plotting routines are retained from the original analysis scripts. Their generated layouts are not an exact reconstruction of the manually arranged manuscript Fig. 4B. The optional `mechanism_display` layout hides some displayed arrows without removing those paths from the fitted model; it is a display variant, not another statistical model.

The analysis concerns within-HCR observational associations, not independent validation of the KFJP identification framework. Report the global fit diagnostics rather than treating the model as globally adequate simply because individual paths are significant. Running these files requires the actual inputs; no synthetic replacement data or fixed coefficients are supplied.
